# Guava Pattern documentation

These Markdown files are the single source of the documentation. The website
(guavapattern.com/docs) fetches them from this folder, so editing a file here
updates the site.

- `manifest.json` lists the pages and their order. Add a page by adding the file and one line there.
- Files are numbered for a readable GitHub folder view; the number is not used by the site.
- `build/` holds the offline CHM build (`build/build-chm.py`, run by `.github/workflows/chm.yml`).
